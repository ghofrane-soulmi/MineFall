# Deploy Minefall: Vercel (web) + Render (game server)

About 15 minutes, all free. You need a GitHub account with the MineFall repository, a
[Vercel](https://vercel.com) account and a [Render](https://render.com) account (both can
"Sign up with GitHub").

```
Players ──▶ Vercel: the web app (Vue)  ──HTTPS + WebSocket──▶ Render: game server ──▶ Render PostgreSQL
```

> 🇫🇷 Vercel héberge le site (les pages). Render héberge le serveur de jeu (qui doit rester
> connecté aux joueurs) et la base de données. Les deux sont gratuits.

## Why two hosts?

Vercel runs server code as short "functions" that stop after each request. The game server
must stay connected to both players for the whole match (WebSockets, 20-second timers, live
games in memory), so it runs on Render, which keeps a real server process alive.

---

## Step 1: the game server on Render (≈ 8 min)

1. Render dashboard → **New +** → **Blueprint**.
2. Connect GitHub and pick the **MineFall** repository. Render reads `render.yaml` and shows:
   - `minefall-api` (web service, Docker, free)
   - `minefall-db` (PostgreSQL, free)
3. It asks for **`CORS_ORIGIN`**: you do not know your Vercel address yet, so type
   `https://minefall.vercel.app` for now (you will fix it in Step 3).
4. Click **Apply**. The first build takes ~5–8 minutes.
5. When `minefall-api` says **Live**, copy its address, e.g.
   `https://minefall-api.onrender.com`, and check it in your browser:
   `https://minefall-api.onrender.com/health` → `{"status":"ok"}`.

What happens on each start: the container applies the database migrations
(`prisma migrate deploy`), then starts the server. `JWT_SECRET` is generated by Render.

> 🇫🇷 Render lit `render.yaml` et crée le serveur + la base tout seul. Note l'adresse du
> serveur (`https://...onrender.com`).

## Step 2: the web app on Vercel (≈ 4 min)

1. Vercel dashboard → **Add New…** → **Project** → import **MineFall** from GitHub.
2. **Root Directory**: click _Edit_ and choose **`apps/web`**. Leave the other build settings:
   they come from `apps/web/vercel.json` (pnpm, `pnpm run build`, output `dist`).
3. **Environment Variables** → add:

   | Name           | Value                                                                                         |
   | -------------- | --------------------------------------------------------------------------------------------- |
   | `VITE_API_URL` | your Render address from Step 1 (no `/` at the end), e.g. `https://minefall-api.onrender.com` |

4. Click **Deploy**. Copy your site address, e.g. `https://minefall.vercel.app`.

> 🇫🇷 Choisis le dossier `apps/web` et ajoute `VITE_API_URL` = l'adresse Render.

## Step 3: connect the two (≈ 1 min)

1. Render → `minefall-api` → **Environment** → set **`CORS_ORIGIN`** to your exact Vercel
   address, e.g. `https://minefall.vercel.app` (several addresses: separate with commas).
2. **Save Changes**: Render restarts the server.

Open your Vercel address in two windows (one private): pick nicknames, click **Play now**
in both, and play. 🎉

> 🇫🇷 Mets l'adresse Vercel dans `CORS_ORIGIN` sur Render : c'est ce qui autorise le site à
> parler au serveur.

## Good to know

- **Free plan sleep:** Render's free server sleeps after 15 minutes without visitors; the
  first visitor then waits about a minute while it wakes up. A paid instance (~$7/month)
  never sleeps.
- **Free database:** Render's free PostgreSQL expires after 30 days. For a long-lived free
  database, create one on [Neon](https://neon.tech) and paste its connection string into
  `DATABASE_URL` on Render instead.
- **Live games live in memory:** a restart or redeploy ends the games in progress (finished
  games and accounts are safe in PostgreSQL).
- **Updates are automatic:** every push to `main` redeploys both Vercel and Render.
- **Vercel preview deployments** use other addresses; add them to `CORS_ORIGIN` if you want
  them to reach the server.

## If something does not work

| Symptom                                                             | Fix                                                                                                  |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| "Cannot reach the server" on the site                               | `VITE_API_URL` missing or wrong on Vercel → fix it, then **Redeploy** (Vite reads it at build time). |
| Nickname works but nothing else / CORS error in the browser console | `CORS_ORIGIN` on Render must be your exact Vercel address (with `https://`, no trailing `/`).        |
| First load takes ~1 minute                                          | The free Render server was asleep: normal.                                                           |
| Render build fails                                                  | Render → `minefall-api` → **Logs**; the same Dockerfile is built by CI on every push.                |
